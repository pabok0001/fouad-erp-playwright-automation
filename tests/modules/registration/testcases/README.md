# Registration — test cases

Put the test cases for each page here, one Markdown file per page, named after the page
(e.g. `patient-registration.md`). Each file should give the **page navigation** (menu path or URL),
the **steps**, the **test data** and the **expected result**. Only the pages listed here get
automated; the resulting specs go to `../tests/` and any test-data tables to `../data/`.
